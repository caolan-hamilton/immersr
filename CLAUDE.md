# Crosstalki

A language-immersion web app: a live AI voice Partner speaks only the Target language and the Learner replies in English. See `GLOSSARY.md` for vocabulary and `docs/adr/` for decisions.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues on `caolan-hamilton/crosstalki` (private), via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
